Projects

Medi

NextGen Medi - Multimodal Disease Prediction System

The Multimodal Disease Prediction System is an AI-driven healthcare solution designed to assist in early and accurate disease detection by analyzing multiple types of patient data simultaneously. This system takes health reports, medical images (X-rays), and textual symptom descriptions as inputs and predicts potential diseases, enabling faster diagnosis and informed medical decision-making.

The core idea of the project is to leverage machine learning and deep learning techniques to process heterogeneous medical data: Health Reports using tabular data models, X-ray Images using CNNs, and Symptoms Text using NLP models like BERT.

Tech Stack: Python, TensorFlow/Keras, scikit-learn, BERT/ClinicalBERT, CNNs, NLP
